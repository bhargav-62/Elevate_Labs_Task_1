# Titanic Dataset - Exploratory Data Analysis (Task 1)

### 1. Project Description
**Goal:** To perform an initial inspection of the Titanic dataset to understand its structure and prepare it for future Machine Learning tasks.  
**Internship:** Part of the AI & ML Internship at Elevate Labs.

---

### 2. Key Findings
* **Dataset Size:** 891 rows and 12 columns.
* **Missing Data:** Identified 177 missing values in 'Age' and 687 in 'Cabin'.
* **Feature Classification:** Successfully categorized variables into Numerical, Categorical, Ordinal, and Binary types.

---

* `Elevate_Labs_Task1_Titanic_Analysis.ipynb`: The Google Colab notebook containing Python code and visualizations.
* `Titanic_Analysis_Report.pdf`: A 1-page summary report of the analysis.
